# CodeVerse

**Интерактивная платформа для изучения JavaScript, Python и алгоритмов — от полного нуля до уровня junior-разработчика.**

Главная идея — учиться через постоянную практику. Почти каждый урок сочетает теорию, анимацию, живой пример, задания и проверку кода. Ошибки здесь — нормальная часть обучения: приложение замечает слабые темы и подбирает задания именно на них.

## Курсы

При первом запуске ученик выбирает курс — и всё приложение подстраивается под него: программа курса, практика, задачи и редактор кода работают на его языке. Курс можно сменить в любой момент, прогресс по каждому сохраняется.

## Платформы

CodeVerse — прогрессивное веб-приложение (PWA): адаптивный интерфейс для телефона и компьютера, установка на **Android, iPhone, Windows, macOS, Linux** и работа в браузере (**Web**). Service worker кэширует приложение и Pyodide для офлайн-работы.

Код учеников выполняется в изолированных Web Worker'ах (JavaScript — песочница с таймаутом, Python — CPython в WebAssembly через [Pyodide](https://pyodide.org)), поэтому бесконечный цикл не повесит приложение, а у кода нет доступа к странице.

## Где открыть

- **Веб и телефон:** https://abyzer-1337.github.io/Codeverse/ — публикуется автоматически (GitHub Actions → GitHub Pages). На телефоне открой ссылку и добавь на главный экран: iPhone — «Поделиться» → «На экран „Домой“», Android — меню ⋮ → «Установить приложение».
- **Компьютер (.exe, .dmg, .AppImage):** раздел [Releases](https://github.com/AbyzeR-1337/Codeverse/releases/tag/desktop-latest) — файлы собираются автоматически при каждом обновлении.
  - `CodeVerse-Setup-*.exe` — установщик для Windows (ярлык на рабочем столе, выбор папки);
  - `CodeVerse-Portable-*.exe` — запуск без установки.
  - Сборка не подписана сертификатом, поэтому Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## Запуск

```bash
npm install
npm run dev          # режим разработки: http://localhost:5173
npm run build        # сборка в dist/ (статические файлы — можно разместить на любом хостинге)
npm run preview      # просмотр собранной версии
npm test             # тесты: эталонные решения всего контента + движок (отладчик, Git, оболочка)
npm run sync-server  # сервер синхронизации на :8787 (PORT, DATA_DIR — переменные окружения)
npm run desktop      # настольное приложение (Electron) в режиме разработки
npm run dist:win     # собрать .exe (установщик + портативная версия) в release/
npm run dist:mac     # .dmg   ·   npm run dist:linux — .AppImage
```

Для Python нужен доступ к `cdn.jsdelivr.net` при первом запуске (дальше — из кэша).

### ИИ-наставник на Claude

В «Настройках» укажи API-ключ Anthropic. Ключ хранится только в браузере и не отправляется на сервер синхронизации. Запросы идут напрямую из браузера к Claude API (модель по умолчанию — Claude Opus 5.5; включён серверный fallback при отказе модели). Для публичного развёртывания лучше проксировать запросы через свой бэкенд, чтобы не раздавать ключи.

### Синхронизация

1. Запусти `npm run sync-server` на сервере (за HTTPS-прокси).
2. На каждом устройстве в «Настройках» укажи адрес сервера и **один и тот же** секретный код.
3. Прогресс, текущий шаг урока, файлы IDE и черновики объединяются автоматически (при запуске, раз в 2 минуты и при возврате во вкладку).


## Как добавлять контент

Курс описан данными в `src/content/course/*.ts`. Урок — массив шагов (`theory`, `animation`, `example`, `quiz`, `predict`, `order`, `match`, `fill`, `findline`, `fixbug`, `code`). Главы без уроков с полем `planned` отображаются в дорожной карте. Экзамены, карточки повторения и статистика по темам формируются автоматически. `npm test` проверяет, что эталонные решения проходят тесты, а ответы «предскажи вывод» совпадают с реальным выводом программ.

Сейчас готово: 3 курса и введение, 98 уроков, более 500 шагов, около 150 заданий с кодом, 32 задачи, 17 пошаговых проектов, 7 мини-игр с бесконечной генерацией заданий. Следующие шаги: уроки по главам дорожной карты (TypeScript, React, Node.js, Flask/FastAPI/Django, боты, ML), публикация в магазинах приложений (Capacitor), аккаунты с входом вместо кода синхронизации, серверный прокси для ИИ.
